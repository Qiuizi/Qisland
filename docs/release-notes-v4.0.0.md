# Qisland v4.0.0

第四个大版本。该知道的，抬眼就知道。

这一版把岛做得更像系统自带的东西：动起来有弹性、玻璃是系统合成的、点一下就回到发消息的那个软件；同时把雨课堂、音乐、天气这些天天用的部分做稳、做全。

## 外观与手感
- **两套玻璃皮肤**：「磨砂玻璃」用 Windows 系统合成的背景模糊（Windows.UI.Composition 宿主背景画刷），不再定时截屏，背后画面变化也不滞后；Win10 或合成不可用时自动退回截屏模糊，托盘「外观」里可选 系统 / 截屏 / 不模糊。
- **新皮肤「液态玻璃」**：参考 iOS 26 的 Liquid Glass——中间几乎透明，外沿一道左上最亮的镜面亮边和内圈斜面亮边，边缘一圈淡淡的磨砂，岛弹动时高光会跟着轻轻晃；跟随系统浅色 / 深色。岛里面的组件卡片、通知列表、按钮和标签也换成同一套液态玻璃样式（共用一份皮肤样式，静态画刷，不加逐帧开销）。
- **阴影修好了**：收起和展开时阴影都均匀落在胶囊四周、只略往下偏，不再出现偏右下的一块灰板。
- **动效**：参考岛仔的弹簧参数重写——展开带一点回弹、收起不回弹，悬停微微胀大，内容随形状逐步出现，翻页带速度的交叉滑动；托盘「动效」可选 完整 / 跟随系统 / 精简。
- **停靠与极简**：可停在顶部居中、左侧或右侧（侧边收起为竖向胶囊，展开从边缘滑出）；极简模式收起时只剩一小段线，靠近才展开。
- **流畅度**：玻璃合成挪到独立线程，动画时 UI 线程每帧从 5–7 ms 降到约 1 ms；内存护栏回收后不再反复触发。
- 12 小时制时钟开关；OLED 防烧屏像素位移（默认关）。

## 点一下就过去
- 点岛上的任何一条（收起的胶囊也一样），直接切到来源软件：系统通知按发通知的应用（含商店应用）打开，微信 / QQ 回到会话窗口，终端里的 AI 会话回到对应的终端窗口，音乐回到播放器或正在播的浏览器标签页，作业打开网页，日程打开日历。
- Win11 下前台切换更可靠；每次跳转都记日志（目标和结果）。岛本身仍然不抢焦点。

## 学习
- **雨课堂更稳**：保存滚动更新的登录 Cookie（DPAPI 加密），疑似掉线要两次确认，网络 / 门户 / 5xx 当临时问题，误判过期每 30 分钟自愈；Cookie 缺失时不再无限重试，直接提示扫码。
- **本机日程**：在月历里新建 / 编辑 / 删除（全天、每周重复、地点），和 .ics 订阅一起提前提醒，DPAPI 加密存在本机。
- **待办提醒与每周重复**：行内显示「⏰ 今天 20:00」，到点岛上提醒，重复待办勾掉自动挪到下一次。

## 音乐
- 支持任何接入系统媒体控制（SMTC）的播放器，网易云 SMTC 与本机日志合并，进度更准。
- 歌词对齐修正：稳定排序、同时间戳的双语行合并为翻译、严格匹配候选（时长差 ≤ 3 秒，排除 Live / Remix / 伴奏）；酷狗、汽水音乐优先读本机已下载的歌词缓存（只读）。

## AI
- **划词翻译**（`Ctrl+Alt+T`）和 **问 AI**（`Ctrl+Alt+K`）：岛上左右对照、复制、替换原文、粘贴到豆包（只粘贴不发送）；快捷键被占用时自动换备用组合。
- **AI 页**：Claude Code、Codex、DeepSeek Harness、Gemini CLI、Cursor、Qwen Code、OpenCode 等会话状态和耗时，Codex / 豆包额度环，DeepSeek / Kimi 余额。豆包会员额度为非官方接口，自愿连接、只读。
- **接入其他 AI 工具**：逐个征得同意后才改配置，改前备份、记进改动账本、一键还原。
- **审批**：只有 Codex 和 DeepSeek Harness 能在岛上点允许 / 拒绝；Claude Code 等你确认时只弹出等待提示。

## 组件
- **天气**：Open-Meteo 7 天 + 逐小时为主（wttr.in 补充），15 分钟刷新；最多 5 个城市，卡片上点地名轮换；快下雨 / 雷阵雨 / 大风 / 高温 / 降温等天气提醒；图标动效。
- **健康**：今天喝水量圆环和按小时柱状图，一键记一杯；连续用电脑时长；喝水 / 久坐提醒（默认关）。
- **剪贴板置顶**：最多 10 条文字，DPAPI 加密落盘。
- **统一设置窗**（托盘「设置…」）：外观与停靠、岛上提示、天气、健康、日历与待办、课程作业、翻译 / AI / 快捷键、接入其他软件，一处改完。

## 已知限制
- 液态玻璃的边缘磨砂是分几圈叠出来的近似渐变，系统合成做不出真正的折射。
- 微信 / QQ 新版来电窗口标题没逐一核对，来电提醒可能认不出（接通后的「通话中」不受影响）。
- 蓝牙电量只有走免提协议（HFP）上报电量的耳机能读到。
