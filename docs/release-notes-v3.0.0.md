# Qisland v3.0.0

第三个大版本：该知道的，抬眼就知道。核心变化：从「能显示东西的岛」变成「知道什么时候该安静的岛」——收起时始终显示时间，提示只临时出现，专注时只放行要紧的。

## 学习
- **课业雷达**：雨课堂 / 学习通作业（扫码登录、只读、低频）在截止前 24 / 3 / 1 小时各提醒一次；交了的不再提醒。
- **课表**：导入 .ics 课表，课前提醒、首页显示今天剩下的课和下一节去哪个教室。
- **日历订阅（新）**：添加 Outlook / Google / 飞书 / 钉钉的 .ics 私密地址，15 分钟刷新；课程组件显示接下来的日程，月历标出有日程的日子；开始前 10 分钟提醒，腾讯会议 / Zoom / Teams / Meet / 飞书 / 钉钉链接一键加入。支持每天 / 每周 / 每月 / 每年重复（含「每月第二个周二」「每月最后一天」这类规则）、例外和改期。

## 从 Mac / iPhone 灵动岛补来的
- **麦克风 / 摄像头占用**：有程序开始用时弹一下，用着时天气旁边留橙点 / 绿点（注册表通知驱动，不轮询）。
- **通话 / 会议**：微信、QQ、腾讯会议、钉钉、飞书、Teams、Zoom 通话或开会时显示「通话中 · 时长」，点一下切回通话窗口；微信 / QQ 来电时展开提醒。
- **专注联动**：自己的专注计时或 Windows 11 专注会话进行中，胶囊只放行审批、通话、1 小时内截止的作业，其余只进列表，结束后汇成一条摘要。
- **蓝牙耳机**：连上 / 断开提示，能读到就显示电量，20% / 10% 低电量提醒。
- **网络**：断网 / 恢复、换 Wi-Fi、校园网需要网页认证（点一下打开登录页）、系统代理开关。开着 Clash / Mihomo TUN 也能看到真实 Wi-Fi。
- **大写 / 数字锁定提示**。
- 托盘「岛上提示」里每一项都能单独关。

## 开发者
- **Codex 审批上岛**：Codex 请求执行命令时在岛上点允许 / 拒绝，100 秒不点就回终端问，不会默认同意。
- **点哪跳哪**：点活动直接切到对应软件 / Codex 会话 / 作业网页。
- **Codex 额度**、DeepSeek Harness 状态、Claude Code / Codex hook 事件。
- `/v1/perf` 增加各监听器的事件计数，方便确认它们是事件驱动的。

## 小而有用
- 通知里的验证码一键复制（只在内存里，不记日志）。
- 输入法中 / 英指示（实验，默认关）。
- 天气地点可以自己设（`weather.txt`），默认按网络位置自动判断；雨课堂默认走 www.yuketang.cn，学校专属域名写进 `yuketang-host.txt`（已登录的不受影响）。
- **对其他软件的改动账本**：Qisland 改过哪些别的软件的配置（Codex hooks、DSH 插件）都记在账上，托盘里一键还原。

## 稳定性
- 全屏判断更准：只要前台窗口看得见的部分盖满整块屏（全屏视频、游戏、F11，以及任务栏自动隐藏时的最大化窗口）岛就让开；没盖满的（任务栏常显时的最大化、贴满屏幕的「还原」窗口）不藏。
- 顶边呼出只认岛正上方那一段，鼠标要停稳一下才展开；收起的岛也要指针停稳才展开，划过去去点标签页 / 关闭按钮不会误触。全屏里照样能呼出。
- 置顶守护：被别的置顶窗口压住、睡眠唤醒、解锁、换分辨率后自动回到最上层和正确位置。
- 媒体会话断开自动重连；更新检查失败 45 分钟后重试；睡醒后网络就绪再拉作业。
- 日历解析放到后台线程，启动不再读加密缓存；修了几处小问题（Codex 额度读取超时边界、蓝牙开关反复时的旧事件、专注摘要上限）。

## 已知限制
- 微信 / QQ 新版来电窗口的标题没在真机上核对，来电提醒可能认不出来（接通后的「通话中」不受影响）。
- 蓝牙电量只有走免提协议（HFP）上报电量的耳机能读到。
- 隐私圆点只在收起显示时间时可见。
